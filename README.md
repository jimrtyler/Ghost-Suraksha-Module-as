# 👻 Ghost সুৰক্ষা মডিউল
**PowerShell-ভিত্তিক Windows আৰু Azure সুৰক্ষা কঠিনীকৰণ সঁজুলি**

> **Windows এণ্ডপইণ্ট আৰু Azure পৰিৱেশৰ বাবে সক্ৰিয় সুৰক্ষা কঠিনীকৰণ।** Ghost এ PowerShell-ভিত্তিক কঠিনীকৰণ কাৰ্যসমূহ প্ৰদান কৰে যিয়ে অপ্ৰয়োজনীয় সেৱা আৰু প্ৰটোকল অক্ষম কৰি সাধাৰণ আক্ৰমণ ভেক্টৰসমূহ হ্ৰাস কৰাত সহায় কৰিব পাৰে।

## ⚠️ গুৰুত্বপূৰ্ণ দাবী পৰিত্যাগ

**পৰীক্ষণ প্ৰয়োজন**: সদায় উৎপাদন-বিহীন পৰিৱেশত প্ৰথমে Ghost পৰীক্ষা কৰক। সেৱাসমূহ অক্ষম কৰিলে বৈধ ব্যৱসায়িক কাৰ্যসমূহত প্ৰভাৱ পৰিব পাৰে।

**কোনো গেৰাণ্টি নাই**: যদিও Ghost এ সাধাৰণ আক্ৰমণ ভেক্টৰসমূহক লক্ষ্য কৰে, কোনো সুৰক্ষা সঁজুলিয়ে সকলো আক্ৰমণ প্ৰতিৰোধ কৰিব নোৱাৰে। এইটো এক ব্যাপক সুৰক্ষা কৌশলৰ এটা উপাদান।

**কাৰ্যক্ষম প্ৰভাৱ**: কিছুমান কাৰ্যই ছিষ্টেম কাৰ্যকৰীতাত প্ৰভাৱ পেলাব পাৰে। স্থাপনৰ আগতে প্ৰতিটো ছেটিং সযত্নে পৰীক্ষা কৰক।

**পেশাদাৰী মূল্যায়ন**: উৎপাদন পৰিৱেশৰ বাবে, সুৰক্ষা পেশাদাৰসকলৰ সৈতে পৰামৰ্শ কৰক যাতে ছেটিংসমূহ আপোনাৰ সংস্থাৰ প্ৰয়োজনৰ সৈতে সংগতিপূৰ্ণ হয়।

## 📊 সুৰক্ষা পৰিস্থিতি

Ransomware ক্ষতি **২০২৫ চনত $৫৭ বিলিয়ন** পৰ্যন্ত পৌঁছিছে, গৱেষণাই সূচায় যে বহুতো সফল আক্ৰমণে মৌলিক Windows সেৱা আৰু ভুল সংৰূপণৰ সুবিধা লয়। সাধাৰণ আক্ৰমণ ভেক্টৰসমূহৰ ভিতৰত আছে:

- **৯০% ransomware ঘটনাই** RDP শোষণ জড়িত কৰে
- **SMBv1 দুৰ্বলতাই** WannaCry আৰু NotPetya ৰ দৰে আক্ৰমণ সক্ষম কৰিছিল
- **নথিপত্ৰ মেক্ৰ'সমূহ** এটা প্ৰাথমিক মেলৱেৰ বিতৰণ পদ্ধতি হৈ আছে
- **USB-ভিত্তিক আক্ৰমণে** এয়াৰ-গেপড নেটৱৰ্কসমূহক লক্ষ্য কৰি থাকে
- **PowerShell অপব্যৱহাৰ** শেহতীয়া বছৰবোৰত উল্লেখনীয়ভাৱে বৃদ্ধি পাইছে

## 🛡️ Ghost সুৰক্ষা কাৰ্যসমূহ

Ghost এ **১৬ টা Windows কঠিনীকৰণ কাৰ্য** আৰু **Azure সুৰক্ষা একত্ৰীকৰণ** প্ৰদান কৰে:

### Windows এণ্ডপইণ্ট কঠিনীকৰণ

| কাৰ্য | উদ্দেশ্য | বিবেচনা |
|----------|---------|----------------|
| `Set-RDP` | ৰিম'ট ডেস্কটপ প্ৰৱেশ পৰিচালনা কৰে | দূৰৱৰ্তী প্ৰশাসনত প্ৰভাৱ পেলাব পাৰে |
| `Set-SMBv1` | পুৰণি SMB প্ৰটোকল নিয়ন্ত্ৰণ কৰে | অতি পুৰণি ছিষ্টেমৰ বাবে প্ৰয়োজন |
| `Set-AutoRun` | AutoPlay/AutoRun নিয়ন্ত্ৰণ কৰে | ব্যৱহাৰকাৰীৰ সুবিধাত প্ৰভাৱ পেলাব পাৰে |
| `Set-USBStorage` | USB সংৰক্ষণ ডিভাইচসমূহ সীমিত কৰে | বৈধ USB ব্যৱহাৰত প্ৰভাৱ পেলাব পাৰে |
| `Set-Macros` | Office মেক্ৰ' সম্পাদন নিয়ন্ত্ৰণ কৰে | মেক্ৰ'-সক্ষম নথিপত্ৰত প্ৰভাৱ পেলাব পাৰে |
| `Set-PSRemoting` | PowerShell ৰিম'টিং পৰিচালনা কৰে | দূৰৱৰ্তী পৰিচালনাত প্ৰভাৱ পেলাব পাৰে |
| `Set-WinRM` | Windows ৰিম'ট মেনেজমেণ্ট নিয়ন্ত্ৰণ কৰে | দূৰৱৰ্তী প্ৰশাসনত প্ৰভাৱ পেলাব পাৰে |
| `Set-LLMNR` | নাম সমাধান প্ৰটোকল পৰিচালনা কৰে | সাধাৰণতে অক্ষম কৰাটো সুৰক্ষিত |
| `Set-NetBIOS` | TCP/IP ৰ ওপৰত NetBIOS নিয়ন্ত্ৰণ কৰে | পুৰণি এপ্লিকেচনত প্ৰভাৱ পেলাব পাৰে |
| `Set-AdminShares` | প্ৰশাসনিক শ্বেয়াৰসমূহ পৰিচালনা কৰে | দূৰৱৰ্তী ফাইল প্ৰৱেশত প্ৰভাৱ পেলাব পাৰে |
| `Set-Telemetry` | তথ্য সংগ্ৰহ নিয়ন্ত্ৰণ কৰে | নিদান ক্ষমতাত প্ৰভাৱ পেলাব পাৰে |
| `Set-GuestAccount` | অতিথি একাউণ্ট পৰিচালনা কৰে | সাধাৰণতে অক্ষম কৰাটো সুৰক্ষিত |
| `Set-ICMP` | পিং সঁহাৰি নিয়ন্ত্ৰণ কৰে | নেটৱৰ্ক নিদানত প্ৰভাৱ পেলাব পাৰে |
| `Set-RemoteAssistance` | ৰিম'ট এছিষ্টেন্স পৰিচালনা কৰে | হেল্প ডেস্ক কাৰ্যত প্ৰভাৱ পেলাব পাৰে |
| `Set-NetworkDiscovery` | নেটৱৰ্ক আবিষ্কাৰ নিয়ন্ত্ৰণ কৰে | নেটৱৰ্ক ব্ৰাউজিংত প্ৰভাৱ পেলাব পাৰে |
| `Set-Firewall` | Windows ফায়াৰৱাল পৰিচালনা কৰে | নেটৱৰ্ক সুৰক্ষাৰ বাবে গুৰুত্বপূৰ্ণ |

### Azure ক্লাউড সুৰক্ষা

| `Set-AzurePrivilegedUsers` | বিশেষাধিকাৰপ্ৰাপ্ত একাউণ্ট নিৰীক্ষণ কৰে | গ্ল'বেল এডমিন অনুমতি |

## 🔍 কাৰ্য বিৱৰণ

### মূল কঠিনীকৰণ কাৰ্যসমূহ

#### নেটৱৰ্ক সেৱাসমূহ
- **RDP**: ৰিম'ট ডেস্কটপ প্ৰৱেশ ব্লক কৰে বা পৰ্ট এলোমেলো কৰে
- **SMBv1**: পুৰণি ফাইল শ্বেয়াৰিং প্ৰটোকল অক্ষম কৰে
- **ICMP**: পুনৰ্গঠনৰ বাবে পিং সঁহাৰি প্ৰতিৰোধ কৰে
- **LLMNR/NetBIOS**: পুৰণি নাম সমাধান প্ৰটোকলসমূহ ব্লক কৰে

#### এপ্লিকেচন সুৰক্ষা
- **Macros**: Office এপ্লিকেচনত মেক্ৰ' সম্পাদন অক্ষম কৰে
- **AutoRun**: অপসাৰণযোগ্য মিডিয়াৰ পৰা স্বয়ংক্ৰিয় সম্পাদন প্ৰতিৰোধ কৰে

#### দূৰৱৰ্তী পৰিচালনা
- **PSRemoting**: PowerShell দূৰৱৰ্তী সেছনসমূহ অক্ষম কৰে
- **WinRM**: Windows ৰিম'ট মেনেজমেণ্ট বন্ধ কৰে
- **Remote Assistance**: ৰিম'ট এছিষ্টেন্স সংযোগসমূহ ব্লক কৰে

#### প্ৰৱেশ নিয়ন্ত্ৰণ
- **Admin Shares**: C$, ADMIN$ শ্বেয়াৰসমূহ অক্ষম কৰে
- **Guest Account**: অতিথি একাউণ্ট প্ৰৱেশ অক্ষম কৰে
- **USB Storage**: USB ডিভাইচ ব্যৱহাৰ সীমিত কৰে

### Azure একত্ৰীকৰণ
```powershell
# Azure টেনাণ্টৰ সৈতে সংযোগ কৰক
Connect-AzureGhost -Interactive

# সুৰক্ষা ডিফল্ট সক্ষম কৰক
Set-AzureSecurityDefaults -Enable

# চৰ্তসাপেক্ষ প্ৰৱেশ সংৰূপণ কৰক
Set-AzureConditionalAccess -BlockLegacyAuth -RequireMFA

# বিশেষাধিকাৰপ্ৰাপ্ত ব্যৱহাৰকাৰী নিৰীক্ষণ কৰক
Set-AzurePrivilegedUsers -AuditOnly
```

### Intune একত্ৰীকৰণ (v2 ত নতুন)
```powershell
# Intune ৰ সৈতে সংযোগ কৰক
Connect-IntuneGhost -Interactive

# Intune নীতিৰ জৰিয়তে স্থাপন কৰক
Set-IntuneGhost -Settings @{
    RDP = $true
    SMBv1 = $true
    USBStorage = $true
    Macros = $true
}
```

## ⚠️ গুৰুত্বপূৰ্ণ বিবেচনা

### পৰীক্ষণ প্ৰয়োজনীয়তা
- **পৰীক্ষাগাৰ পৰিৱেশ**: প্ৰথমে বিচ্ছিন্ন পৰিৱেশত সকলো ছেটিং পৰীক্ষা কৰক
- **পৰ্যায়ক্ৰমিক স্থাপন**: সমস্যা চিনাক্ত কৰিবলৈ ক্ৰমান্বয়ে ৰল আউট কৰক
- **পুনৰ্প্ৰত্যাৱৰ্তন পৰিকল্পনা**: প্ৰয়োজন হ'লে পৰিৱৰ্তনসমূহ বিপৰীত কৰিব পাৰে নিশ্চিত কৰক
- **নথিকৰণ**: আপোনাৰ পৰিৱেশৰ বাবে কোনবোৰ ছেটিং কাম কৰে ৰেকৰ্ড কৰক

### সম্ভাৱ্য প্ৰভাৱ
- **ব্যৱহাৰকাৰী উৎপাদনশীলতা**: কিছুমান ছেটিঙে দৈনন্দিন কৰ্মপ্ৰবাহত প্ৰভাৱ পেলাব পাৰে
- **পুৰণি এপ্লিকেচন**: পুৰণি ছিষ্টেমসমূহক নিৰ্দিষ্ট প্ৰটোকলৰ প্ৰয়োজন হ'ব পাৰে
- **দূৰৱৰ্তী প্ৰৱেশ**: বৈধ দূৰৱৰ্তী প্ৰশাসনৰ ওপৰত প্ৰভাৱ বিবেচনা কৰক
- **ব্যৱসায়িক প্ৰক্ৰিয়া**: ছেটিংসমূহে গুৰুত্বপূৰ্ণ কাৰ্যসমূহ ভংগ নকৰে যাচাই কৰক

### সুৰক্ষা সীমাবদ্ধতা
- **গভীৰতাত প্ৰতিৰক্ষা**: Ghost সুৰক্ষাৰ এটা স্তৰ, সম্পূৰ্ণ সমাধান নহয়
- **চলমান পৰিচালনা**: সুৰক্ষাৰ বাবে নিৰন্তৰ নিৰীক্ষণ আৰু আপডেটৰ প্ৰয়োজন
- **ব্যৱহাৰকাৰী প্ৰশিক্ষণ**: কাৰিকৰী নিয়ন্ত্ৰণসমূহ সুৰক্ষা সজাগতাৰ সৈতে যোৰ কৰিব লাগিব
- **ভাবুকি বিৱৰ্তন**: নতুন আক্ৰমণ পদ্ধতিয়ে বৰ্তমান সুৰক্ষাসমূহ বাইপাছ কৰিব পাৰে

## 🎯 উদাহৰণ আক্ৰমণ দৃশ্যপট

যদিও Ghost এ সাধাৰণ আক্ৰমণ ভেক্টৰসমূহক লক্ষ্য কৰে, নিৰ্দিষ্ট প্ৰতিৰোধ সঠিক কাৰ্যকৰীকৰণ আৰু পৰীক্ষণৰ ওপৰত নিৰ্ভৰ কৰে:

### WannaCry-শৈলীৰ আক্ৰমণ
- **প্ৰশমন**: `Set-Ghost -SMBv1` দুৰ্বল প্ৰটোকল অক্ষম কৰে
- **বিবেচনা**: নিশ্চিত কৰক কোনো পুৰণি ছিষ্টেমক SMBv1 ৰ প্ৰয়োজন নাই

### RDP-ভিত্তিক Ransomware
- **প্ৰশমন**: `Set-Ghost -RDP` ৰিম'ট ডেস্কটপ প্ৰৱেশ ব্লক কৰে
- **বিবেচনা**: বিকল্প দূৰৱৰ্তী প্ৰৱেশ পদ্ধতিৰ প্ৰয়োজন হ'ব পাৰে

### নথিপত্ৰ-ভিত্তিক Malware
- **প্ৰশমন**: `Set-Ghost -Macros` মেক্ৰ' সম্পাদন অক্ষম কৰে
- **বিবেচনা**: বৈধ মেক্ৰ'-সক্ষম নথিপত্ৰত প্ৰভাৱ পেলাব পাৰে

### USB-বিতৰিত ভাবুকি
- **প্ৰশমন**: `Set-Ghost -USBStorage -AutoRun` USB কাৰ্যকৰীতা সীমিত কৰে
- **বিবেচনা**: বৈধ USB ডিভাইচ ব্যৱহাৰত প্ৰভাৱ পেলাব পাৰে

## 🏢 এণ্টাৰপ্ৰাইজ বৈশিষ্ট্যসমূহ

### গ্ৰুপ পলিচি সমৰ্থন
```powershell
# গ্ৰুপ পলিচি ৰেজিষ্ট্ৰিৰ জৰিয়তে ছেটিং প্ৰয়োগ কৰক
Set-Ghost -SMBv1 -RDP -AutoRun -GroupPolicy

# GP সতেজ কৰাৰ পিছত ছেটিংসমূহ ডমেইন-ব্যাপী প্ৰয়োগ হয়
gpupdate /force
```

```powershell
# পৰিচালিত ডিভাইচসমূহত নীতিসমূহ স্বয়ংক্ৰিয়ভাৱে স্থাপন হয়
```

### অনুপালন প্ৰতিবেদন
```powershell
# সুৰক্ষা মূল্যায়ন প্ৰতিবেদন সৃষ্টি কৰক
Get-Ghost | Export-Csv -Path "SecurityAudit-$(Get-Date -Format 'yyyy-MM-dd').csv"
```

## 📚 সৰ্বোত্তম পদ্ধতি

### প্ৰি-স্থাপন
1. **বৰ্তমান অৱস্থা নথিভুক্ত কৰক**: পৰিৱৰ্তনৰ আগতে `Get-Ghost` চলাওক
2. **সম্পূৰ্ণৰূপে পৰীক্ষা কৰক**: উৎপাদন-বিহীন পৰিৱেশত বৈধকৰণ কৰক
3. **পুনৰ্প্ৰত্যাৱৰ্তন পৰিকল্পনা কৰক**: প্ৰতিটো ছেটিং কেনেকৈ বিপৰীত কৰিব জানক
4. **অংশীদাৰ পৰীক্ষা**: নিশ্চিত কৰক ব্যৱসায়িক ইউনিটে পৰিৱৰ্তনসমূহ অনুমোদন কৰে

### স্থাপনৰ সময়ত
1. **পৰ্যায়ক্ৰমিক দৃষ্টিভংগী**: প্ৰথমে পাইলট গ্ৰুপসমূহত স্থাপন কৰক
2. **প্ৰভাৱ নিৰীক্ষণ কৰক**: ব্যৱহাৰকাৰীৰ অভিযোগ বা ছিষ্টেম সমস্যা চাওক
3. **সমস্যা নথিভুক্ত কৰক**: ভৱিষ্যতৰ সন্দৰ্ভৰ বাবে যিকোনো সমস্যা ৰেকৰ্ড কৰক
4. **পৰিৱৰ্তনসমূহ যোগাযোগ কৰক**: ব্যৱহাৰকাৰীসকলক সুৰক্ষা উন্নতিৰ বিষয়ে অৱগত কৰক

### স্থাপনৰ পিছত
1. **নিয়মীয়া মূল্যায়ন**: ছেটিংসমূহ যাচাই কৰিবলৈ পৰ্যায়ক্ৰমে `Get-Ghost` চলাওক
2. **নথিকৰণ আপডেট কৰক**: সুৰক্ষা সংৰূপণসমূহ বৰ্তমান ৰাখক
3. **কাৰ্যকৰীতা পৰীক্ষা কৰক**: সুৰক্ষা ঘটনাসমূহৰ বাবে নিৰীক্ষণ কৰক
4. **নিৰন্তৰ উন্নতি**: ভাবুকি পৰিস্থিতিৰ ভিত্তিত ছেটিং সমন্বয় কৰক
